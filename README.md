# Welcome to my Portfolio project

## Project info

**URL**: https://Dvir-Levy.netlify.app

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Lovable AI

## What Cloud technologies are used for this project?
- AWS Lambda, for sending the "Get in touch" emails
- All assets are stored in AWS Buckets

## CI/CD
This website is deployed on Netlify.
Once a pull request is approved and merged into the main branch,
an automated CI/CD pipeline runs npm run build and deploys the output from the dist directory.
